Feedstock for [rcdaq](https://github.com/sPHENIX-Collaboration/rcdaq) — part of [hep-forge](https://anaconda.org/hep-forge).
Builds linux-amd64 + linux-arm64 in one matrix workflow and uploads to the
[hep-forge](https://anaconda.org/hep-forge) Anaconda channel.

RCDAQ: the data acquisition system of sPHENIX and EIC detector R&D

## Architectures

State per architecture: see the platforms badge above or [anaconda.org/hep-forge/rcdaq](https://anaconda.org/hep-forge/rcdaq).


## Install

```bash
conda install -c hep-forge -c conda-forge rcdaq
```
